\title{\sysname: Collocation-Aware, End-to-End Benchmarking of
Machine-Learning Pipelines}

\author{Anonymous Author(s)}
\affiliation{\institution{Anonymous Institution}\city{}\country{}}

\begin{abstract}
Standardized ML benchmarks measure isolated models on isolated accelerators.
Production ML systems are neither: agentic and retrieval-augmented pipelines
execute cyclic, input-dependent graphs; their performance is set by data
movement as much as by compute; and they run collocated with other workloads.
We present \sysname{}, a framework that benchmarks ML \emph{pipelines} end to
end: cyclic stage graphs declared in configuration, open- and closed-loop
load generation with arrival-trace verification, and per-process
instrumentation that makes collocated pipelines separately attributable.

Because a benchmark is an instrument, we first bound \sysname{}'s own
footprint. On the M2~Pro, bare dispatch costs
\SIrange{60}{85}{\micro\second} per stage with a depth-flat marginal
cost; wrapping a real GPU fine-tune measures $-0.05\%$ [$-0.29,+0.14$]
per step --- indistinguishable from zero --- and the tracing layer adds
$+2.1\%$ on that workload, a per-span cost we account for wherever it
matters. We then run three case studies on two unified-memory
machines (\SI{16}{\giga\byte} Apple M2~Pro; \SI{128}{\giga\byte} NVIDIA
GB10), chosen because shared-memory platforms concentrate contention where
per-device counters cannot attribute it. A \emph{staged contention study}
descends from a production-shaped symptom (RAG serving degraded by collocated
indexing) toward mechanism, changing exactly one configuration element per
step; it tests the hypothesis that degradation is priced in co-runner memory
traffic rather than co-runner identity, with prefill/decode asymmetry as a
counter-free control \pending{outcome}. A \emph{topology study}
restructures an agentic RAG pipeline by configuration alone --- one large
model versus a graph of small specialists, with size-matched and
shared-instance controls --- reporting speed with explicitly bounded answer-%
quality differences. Finally, MLPerf Inference's four load \emph{patterns}
are reproduced as \sysname{} scheduler configurations, verified from arrival
traces. Configurations, traces, and analysis scripts will be released.
\end{abstract}
